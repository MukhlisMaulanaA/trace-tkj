# User Guide

## Getting started

Sign in using the URL supplied by your administrator. The application opens the **Projects** and **Purchase Orders** navigation in the admin area. Labels in the application are primarily Indonesian; this guide uses the screen labels you will see.

Use a desktop browser when possible: line items and timelines are easier to review on a larger screen.

## Projects

### Create a project

1. Open **Projects** and select **Create**.
2. Enter **PIC/Penanggung Jawab**, **Nomor Quotation**, **Nama Project**, **Kustomer**, and **Lokasi Project**.
3. Optionally enter **Kontak Person Customer**.
4. Save.

The application generates the **ID Project**. It also creates a protected `Project Created` entry at 0% in **Timeline Progres**.

### Update project progress

1. Open the project and locate **Timeline Progres**.
2. Select **Tambah Progress**.
3. Enter the date/time, percentage (0–100), and a concise description of the milestone.
4. Save.

The timeline is chronological. Its headline percentage is taken from the most recent user-entered update, not the average of every update. You may edit or delete user entries; the initial system entry cannot be changed in the interface.

## Purchase orders

### Create a PO

1. Open **Purchase Orders** and select **Create**.
2. Enter the required **Nomor PO** and **Tanggal PO**. The **ID PO** is generated by the system.
3. Select a **Project**. The customer, location, quotation number, and PIC are copied into the PO.
4. Confirm or adjust the copied PO details. These changes affect only this PO.
5. Upload the required **File PDF Client** (PDF, maximum 10 MB).
6. Set discount, DPP, and PPN as required, add notes if needed, then save.

New POs start as `draft`. The normal form does not provide a way to change this status.

### Add PO items

1. Open the PO and use **Item Purchase Order**.
2. Select **Tambah Item**.
3. Enter the description, quantity, unit (**SAT**), and unit price. **Section / Grup** is optional and groups items in the on-screen and printed PO.
4. Check the calculated **Total Price** and save.

Each line total is quantity × unit price. The system recalculates the PO subtotal and grand total after each item change. Items may be added, edited, or deleted only while the PO is a draft.

### Understand totals

1. **Subtotal** is the total of saved PO items.
2. Enabled discount is deducted to create subtotal after discount.
3. Enabled DPP is calculated from subtotal after discount.
4. Enabled PPN is calculated from DPP if DPP is enabled, otherwise from subtotal after discount.
5. **Grand Total** is subtotal after discount plus PPN.

Discount can be a percentage or a rupiah amount. Nominal discount cannot be greater than the subtotal. With DPP enabled, PPN is 12% of DPP; without DPP, it is 11% of subtotal after discount.

### Open or print a PO

From the PO detail page:

- **PO Client** opens the uploaded client PDF.
- **Dokumen PO** opens the generated TKJ document in a new tab.
- Choose **Print / Save PDF** in that document to print or save it using the browser print dialog.

Direct edits in the printable page are for print formatting only and are not saved. Make permanent corrections in the PO itself.

## Invoice progress

### Record an invoice

1. Open the PO and locate **Invoice Progress Timeline**.
2. Select **Tambah Invoice**.
3. Enter invoice title/number, date, optional description, and an optional PDF (maximum 20 MB).
4. Enter either **Invoice Amount** or **Progress Percentage**; the other value is calculated from the PO grand total.
5. Save.

Payment progress is the combined saved invoice amounts divided by the PO grand total. The remaining amount displayed while entering an invoice includes the invoice currently being entered.

Check that all invoices together do not exceed the grand total. The interface shows the remaining balance but does not block overpayment entries. Use **Update** or **Delete** to correct an invoice; timeline order follows invoice date.

## Good practices and help

- Create the project before the PO to avoid duplicate data.
- Add a meaningful, dated update for each project milestone.
- Recheck discount and tax settings after item changes.
- Retain source PDFs in the record and use the generated document for operational distribution.

| Problem | Check |
| --- | --- |
| Project cannot be selected in PO | Save the project, then search by ID, name, customer, or location. |
| PO total is unexpected | Confirm saved items, quantity/unit price, then discount, DPP, and PPN settings. |
| Cannot edit items | The PO may no longer be a `draft`. |
| PDF cannot open | Confirm upload and ask an administrator to check storage access. |
| Invoice percentage is unexpected | Review all saved invoices and the current PO grand total. |
